# Monty Hall Simulation 🚪🐐🚗

A clean, minimalist Python simulation of the classic **Monty Hall Problem** built in a single Jupyter Notebook. 

## About the Project
This project uses object-oriented Python and NumPy to simulate the Monty Hall game show scenario. It demonstrates why switching doors always yields a ~66.7% win rate compared to staying (~33.3%). 

It also highlights the **Law of Large Numbers**, showing how high sample sizes ($N$) eliminate random noise and stabilize win rates, while small sample sizes exhibit wild variance.

## How to View/Run
You can view the fully rendered notebook directly in your browser by clicking on the `monty_hall.ipynb` file above. 

If you want to run it locally:
1. Clone this repository.
2. Ensure you have `numpy` installed.
3. Open the notebook in Jupyter or VS Code and run the cells!
